# BLESSHOP — тема Shopify «живой космос»

Код темы магазина BLESSHOP (xr5jrm-v9.myshopify.com), черновик
«BLESSHOP Clean Home — живой космос».

Структура — стандартная тема Shopify:

- `layout/` — каркас страниц (`bls-home.liquid` — основной макет нового дизайна)
- `sections/` — блоки страниц (`bls-hero.liquid` — первый экран с космосом)
- `snippets/` — общие куски (`bls-veil.liquid` — переходы, нижняя панель, линза в категориях; `bls-speed.liquid` — мгновенные переходы и эконом-режим)
- `templates/` — какие блоки стоят на какой странице
- `assets/`, `config/`, `locales/` — стили, скрипты, настройки, переводы

Не сохранено: `assets/blesshop-preview.png` (картинка-превью темы, 2 МБ).

Подключение к Shopify: Интернет-магазин → Темы → Добавить тему → Подключить из GitHub → выбрать этот репозиторий и ветку `main`.
